# Beyblade X Collection Manager

A personal collection management and customization application for Beyblade X.

## Project Goal

The goal of this project is to create an application that allows users to easily catalog, visualize, and customize their Beyblade X collection.

Instead of manually entering every individual component, users will be able to search for a Beyblade product from a catalog and add the complete product to their collection.

For example:

`BX Cobalt Drake 4-60F`

The application will identify the product and its components:

- Blade: Cobalt Drake
- Ratchet: 4-60
- Bit: Flat (F)

## Planned Core Features

- Searchable Beyblade X product catalog
- Personal collection tracking
- Automatic part identification from purchased products
- Blade, Ratchet, and Bit inventory tracking
- Compatibility-aware Beyblade customizer
- Visual collection browser
- Interactive 3D Beyblade models
- Saved custom combinations
- Support for Beyblade X product lines such as BX, UX, and CX

## Future Features
