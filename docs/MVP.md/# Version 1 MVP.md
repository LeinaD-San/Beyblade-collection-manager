# Version 1 MVP

## Goal

Create a working Beyblade X collection manager that allows a user to search for a Beyblade product, add it to their collection, view its included parts, and create compatible custom combinations.

## Core Features

### 1. Catalog Search
- Search by Beyblade name
- Search by product code
- Support flexible formatting
- Example:
  - `BX Cobalt Drake 4-60F`
  - `cobalt drake`
  - `bx cobalt drake 460f`

### 2. Add to Collection
- Select a product from the catalog
- Add the complete product to the user's collection
- Automatically identify its included parts

Example:

Cobalt Drake 4-60F

- Blade: Cobalt Drake
- Ratchet: 4-60
- Bit: Flat

### 3. Collection Viewer
- Show owned Beyblades visually
- Display product name
- Display product line
- Display quantity owned
- Open a Beyblade to view more details

### 4. Beyblade Detail View
- Product name
- Product code
- Product line
- Blade
- Ratchet
- Bit
- Image or model preview

### 5. Parts Inventory
Track owned:

- Blades
- Ratchets
- Bits

### 6. Custom Combo Builder
Allow users to select:

- Blade
- Ratchet
- Bit

Only compatible parts should be available.

### 7. Saved Combos
Users can save custom Beyblade combinations.

## Not Included in Version 1

These features will be added later:

- QR scanning
- Battle tracking
- Wishlist
- Marketplace pricing
- Advanced statistics
- Automatic online catalog updates
- Full 3D model library

## Version 1 Success Criteria

Version 1 is complete when a user can:

1. Search for a Beyblade
2. Add it to their collection
3. View the Beyblade and its parts
4. See their owned parts
5. Build a compatible custom Beyblade
6. Save the custom combination
